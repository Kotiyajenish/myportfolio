Track anonymous website visitors and page visits with unique visitor IDs.

== Description ==
Jenish Search Tracker helps you monitor anonymous visitor activity on your website for analytics purposes.

Features include:
* Unique visitor identification using cookies
* Page visit logging
* Visit count tracking
* Location detection (country, region, city)
* Simple admin dashboard to view visitor data

This plugin does not collect personal data and is designed for basic analytics insights.

== Installation ==
1. Upload the plugin folder to `/wp-content/plugins/`
2. Activate the plugin through the WordPress admin
3. Open **Visitor Tracking** from the admin menu
